Driver Drowsiness Detection.

A Python desktop prototype using OpenCV, plus a separate browser demo that uses MediaPipe Face Landmarker to detect prolonged eye closure with your webcam.

How the prototype works

Camera input

Reads frames from the default webcam and mirrors the preview for a familiar front-camera view.

Face and eye detection

Uses OpenCV Haar cascade classifiers to locate the largest face and search for eyes in the upper face region.

Alert state machine

Tracks how long eyes are not detected while a face remains visible and triggers one alert per sustained episode.

Technology stack

Run locally on Windows

py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py

Connect a webcam and allow camera access in your operating system. The app opens as a desktop window; it does not run inside the portfolio website.

Automated tests

python -m unittest discover -s tests -v

The tests cover the monitor state machine: awake, early eye non-detection, sustained alert, reset after eyes return, lost-face reset and invalid threshold handling. The webcam feed itself needs a manual test on the target computer.

Important safety limitation: This is an educational prototype, not a certified driver-monitoring or driver-assistance device. Haar cascades can miss eyes because of lighting, glasses, face angle or camera quality. Do not rely on it to prevent accidents and never operate or test it while driving.
