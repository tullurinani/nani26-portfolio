What is included

Image preparation

Corrects image orientation, converts to RGB, resizes to 224 × 224 and applies MobileNetV2 preprocessing.

Training pipeline

Uses folder-per-class images, train / validation split, augmentation, frozen MobileNetV2 feature extraction and early stopping.

Prediction interface

Shows the top class and confidence values from your trained model, with a clear missing-model state before training.

Technology stack

PythonTensorFlow / KerasMobileNetV2StreamlitPillowNumPy

Prepare your dataset

Place labelled images into one folder per class. Use class labels that match your dataset and licence; the sample below is only an example of the folder structure.

data/
└── rice-leaf-disease/
    ├── healthy/
    ├── leaf_blast/
    └── brown_spot/

Install, train and run

py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

python train.py --data data/rice-leaf-disease --epochs 12 --batch-size 32
streamlit run app.py

Training creates a model file and class-name metadata in the models folder. The first training run downloads MobileNetV2 ImageNet weights, so an internet connection is needed unless those weights are already cached.

Model status: This repository does not include a labelled rice-leaf dataset or trained model weights. The six automated tests validate preprocessing, class-name loading and prediction ranking; they do not measure disease-classification accuracy. No 92% accuracy claim is made for this new implementation. Evaluate a trained model on a separate held-out test set before using it. This project is a learning aid, not an agronomic diagnosis or treatment recommendation.
