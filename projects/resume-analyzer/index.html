Resume Analyzer AI.

A recruitment workflow learning project that parses PDF and DOCX resumes, extracts useful profile signals, prepares interview prompts and lets authorised staff review candidate submissions.

What the project does

The application demonstrates a structured flow from candidate registration through resume upload and interview practice to staff review.

Resume parsing

Extracts document text and looks for skills, education and experience signals in a PDF or DOCX file.

Interview prompts

Generates explainable, rule-based questions from the skills and details found in the uploaded resume.

Review workflow

Provides a staff-only dashboard for viewing candidate submissions and updating application status.

Run locally

The Django application is deployed at resume.nani.shop; the custom domain will open after DNS verification. To run a local copy, use the commands below.

py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

Open http://127.0.0.1:8000/ after the development server starts. Use the staff account created with createsuperuser to access the review dashboard.

Privacy and responsible use: This is a learning project, not a production recruitment platform. The GitHub repository remains public and its older history needs to be cleaned and made private before any real candidate data is used. Use synthetic test data only for now. Candidate resumes and interview recordings are private personal data. The application now uses hashed candidate passwords, staff-only review endpoints and authenticated file routes. Production use still requires a security review, HTTPS, private storage, access auditing, retention controls and a clear consent process. It should not make hiring decisions automatically.
